# Brand icons

Bundled SVG artwork copied from `yetone/magpie`, commit
`8a99473e`, `internal/gui/assets/icons/`, on 2026-10-22.
The collection uses Lobe Icons artwork. Both upstream MIT notices are included.
Brand marks remain trademarks of their respective owners.

The original SVG paths and colors are retained. Monochrome marks inherit the
route or text color. No icon is fetched at runtime.

Reference brand pages: https://cursor.com/brand and https://opencode.ai/brand.
Codex uses the OpenAI knot as requested. Claude Code uses its pixel mascot;
Claude Desktop uses the Claude star. Gemini CLI has its own terminal mark.
