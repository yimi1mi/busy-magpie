使用指南 · v1.3.10

把实时路由放在桌面上

  • 移动和缩放按住顶部小圆点约 0.15 秒拖动，拖边框调整大小。
  • 找到功能右上角 ··· 可查看模型用量、设置和紧凑模式。
  • 读懂用量单击 token 切换时间窗；模型用量里可查看各模型占比。
  • 召回挂件点击托盘图标，或按 Ctrl+Alt+M 显示 / 隐藏。

普通内容区域点击穿透；菜单和面板展开时临时接收操作。

卸载说明

删除 magpie 插件不会删除桌面应用。停止使用时，还需通过系统应用管理或安装目录中的卸载程序移除 Busy Magpie。
